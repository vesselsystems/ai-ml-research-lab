# Security

This repository runs an offline experiment over a public dataset; it is not an API or decision service. Do not add credentials, private customer data, or fitted artifacts containing sensitive information.

Please do not open a public issue containing secrets or private data. Revoke exposed credentials immediately, then contact the repository owner through a private GitHub channel with the repository name, affected revision, and a minimal reproduction. There is no security response SLA for this learning repository.

Model results are not authorization, eligibility, pricing, or treatment decisions. Review source terms before redistributing data.
