Generated by `python scripts/run_ablation.py`. Same data snapshot, seed 42, and
stratified 80/20 split as the main experiment.
Holdout n = 1409, positive rate 0.2654.
The hypotheses were written in the script's docstring before the first run.

Paired bootstrap of the ROC-AUC difference (1,000 row resamples, seed 42):

| Comparison | Difference | 95% interval | Share of resamples where first is higher |
| --- | ---: | ---: | ---: |
| H1: logistic (balanced) - forest | 0.0047 | -0.0046 to 0.0136 | 0.843 |
| H2: logistic (unweighted) - logistic (balanced) | 0.0006 | -0.0004 to 0.0015 | 0.872 |

## Reading the result

- **H1:** the paired interval contains 0, so the two models are not distinguishable on ROC-AUC with this holdout. The prediction was that it contains 0: confirmed.
- **H2:** removing class weights changed ROC-AUC by 0.0006 and ECE from 0.1504 to 0.0253 (forest 0.0860); the mean predicted probability moved from 0.416 to 0.268 against a base rate of 0.265. Prediction confirmed.

Caveats: one split, one seed, and a holdout that also produced the main results. The
unweighted model flags fewer customers at 0.5, so its precision and recall differ;
the choice between them is a threshold and cost decision, not a calibration result.

Environment: Python 3.12.10, scikit-learn 1.9.0, pandas 3.0.5, numpy 2.5.2.
